# ES6 Data Manipulation

## Description
This project focuses on manipulating data in JavaScript using modern ES6 features.
It covers working with arrays, typed arrays, and advanced data structures.

## Learning Objectives
At the end of this project, you should be able to explain:

- How to use `map`, `filter`, and `reduce` on arrays
- Typed arrays in JavaScript
- The `Set`, `Map`, and `WeakMap` data structures

## Requirements
- Ubuntu 20.04 LTS
- Node.js 20.x.x
- npm 9.x.x or higher
- Allowed editors: vi, vim, emacs, Visual Studio Code
- All files must:
  - Use the `.js` extension
  - End with a new line
- All functions must be exported
- Code must pass ESLint and Jest tests
