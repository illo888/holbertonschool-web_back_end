# Node JS Basic

## Description
This project introduces the basics of Node.js.  
It focuses on running JavaScript outside the browser, handling standard input/output,
and working with core Node.js features.

---

## Learning Objectives
At the end of this project, you should be able to explain:

- What Node.js is and how it works
- How to use `process.stdin` and `process.stdout`
- How to read input from the command line
- How to handle events in Node.js
- How to run JavaScript files using Node.js

---

## Requirements
- Ubuntu 20.04 LTS
- Node.js 20.x.x
- npm 9.x.x or higher
- Allowed editors:
  - vi
  - vim
  - emacs
  - Visual Studio Code
- All files must:
  - Use the `.js` extension
  - End with a new line
- Code must run using:
  ```bash
  node filename.js
